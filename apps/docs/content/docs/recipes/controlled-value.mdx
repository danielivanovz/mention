---
title: Controlled value
description: Use standard React textarea state and form props.
---

The textarea owns its value. Pass normal `value` and `onChange` props to `Mention.Input`.

```tsx
import { useState } from "react";
import { Mention } from "@danielivanov/mention";

type Person = { id: string; name: string };
const people: Person[] = [{ id: "alice", name: "Alice" }];

export function MessageInput() {
  const [value, setValue] = useState("");
  return (
    <Mention.Root items={people} getKey={p => p.id} getLabel={p => p.name}>
      <Mention.Input name="message" value={value}
        onChange={e => setValue(e.currentTarget.value)} aria-label="Message" />
      <Mention.Popover aria-label="People">
        <Mention.List<Person>>
          {p => <Mention.Item value={p}>{p.name}</Mention.Item>}
        </Mention.List>
      </Mention.Popover>
    </Mention.Root>
  );
}
```

Typing and mention insertion both notify the supplied handler. `ref`, `onBlur`, `onInput`, and `onKeyDown` are also preserved. A consumer key handler can call `preventDefault()` to override Mention's keyboard handling.

With the standalone hook, pass props into its getter:

```tsx
<textarea {...mention.getInputProps({
  value,
  onChange: e => setValue(e.currentTarget.value),
  "aria-label": "Message",
})} />
```

An `onSelect` callback is a notification of insertion, not an inventory of mentions still present in the document. Users can delete or replace text afterward. If mentions need stable identities and round-trip serialization, store them in an editor document using [an editor adapter](/docs/integrations/rich-text).
